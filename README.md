# Suisei Loading 26

After Effects 原生重制工程与基础矢量素材。

## 内容

- `deliverables/Suisei_Loading_Rebuild_v07.aep`：可编辑 AE 工程。
- `deliverables/Suisei_Loading_Editable_Project_v07.json`：工程结构、关键帧和表达式导出。
- `docs/Preview_Details_v07.html`：本地逐帧对照页。
- `vector_sources/v07/`：星盘、图标和 SVG/JSON 几何源。
- `analysis/`：逐帧测量、星爆覆盖、圆圈线宽和回入运动资料。

## 版本

v07 为 1280x720、30 fps、2395 帧、79.833333 秒循环。星盘、文字环、星芒、图标和背景使用 AE 原生图层，SVG 作为可审阅的几何源。

预览视频和原始 `sc.mp4` 未放入普通 Git 提交：它们超过 GitHub 普通 Git 的 100 MiB 单文件限制。
