# v07 标题闪烁与图标精修分析

## 标题最右四角星

源片按 30 fps 解码。稳定侧标题（20–70 秒）的大四角星中心约为 source `(419.5,342.3)`，不是右侧两个小星点。它以约 81 帧（2.7 秒）为周期收缩到几乎不可见再长回；完整状态常保持约 4 帧，收缩到 30% 约 2 帧，随后 5 帧左右接近 0，回升也分段完成。f608–612（20.2667–20.4 秒）为完全暗态，f620 后恢复完整。亮度核心仍接近白色，故主要参数是 scale，不是对整颗星做正弦 opacity。

精确帧键、循环表达式和中心标题 74.3–76.8 秒独立入场/二次收缩键见 `title_glint.json`。后段不能套用稳定标题周期：源 75.667–75.8 秒再次消失，75.9 秒重新长出。建议用独立原生凹四角 Bézier 星，宽高约 0.8，低强度 Glow 只加在轮廓副本。

## 图标精修

`icons_v07_refined.json` 是完整 16 图标替换数据，仅修改 3 hourglass、4 crescent_moon、10 double_axe、15 wide_brim_hat。其余 12 项与 v06 字节级内容保持一致。新图标使用可编辑 points 与可选 inTangents/outTangents，`role` 区分 outline 和 engraving；不包含截图、不包含最终光栅。

- 月牙沿 `moon_fuller.json` 的解析圆弧轮廓，保留现有源锚点。
- 帽子改成源中横向弯曲的宽檐帽，加入有限的边缘刻线；没有把裁切区域编造成新文字。
- 斧头改成窄而圆的双刃，缩短刀刃并加入少量内缘刻线。
- 沙漏改为椭圆车削上下盖、连续玻璃腰线和少量右侧刻线。

对应 SVG 仅用于检查与导入参考，实际 AE 使用 JSON native paths。`refinement_metadata.json` 记录未修改索引、锚点策略和路径统计。
