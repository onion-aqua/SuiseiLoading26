# v07 帧级细节更新

本版以 `sc.mp4` 的逐帧分析为主，在 v06 的原生 AE 工程上继续编辑，保留可编辑文字、Bezier 路径、Mask、Trim Paths、关键帧和表达式。

## 本次修改

- 74.2 秒金色圆圈保持原片半径运动，屏幕线宽调到约 2.2 px、100% 不透明度。逐帧测量结果：源 FWHM 2.9 px、当前约 2.6 px，半径误差约 0.3 px。
- 77 秒回入采用独立星盘世界缩放：源参考在 77.5 秒约 0.7045、78 秒约 0.9155、78.5 秒约 1.0046，79.17 秒约 1.0224 后回正。星座分支增加约 2.6% 的局部回弹和最多 1.1° 的轻微旋转；这是按用户要求在逐帧参考基础上的细化估计，原片本身没有高置信反复摆荡。
- 1 秒附近加入源中实际存在的局部金色四/八芒星闪耀，32 个语义测量点使用独立帧键；补 12 个白色亮芯，保持低幅度亮度变化，避免整张网格统一闪烁。
- 箭头所指标题右端大四角星改为圆滑凹四角 Bezier 星，稳定段按 81 帧/2.7 秒缩放收缩到近乎消失再恢复；74–76 秒使用独立的入场、收缩和再次出现时间线。
- 月牙、沙漏、双刃斧、宽檐帽采用少量语义 Bezier 轮廓与刻线精修；SVG 原稿在 `vector_sources/v07/icons`，AE 内使用原生路径，不依赖 SVG 外部文件。
- 对金色图标、局部亮芯和标题星芒加入低强度 Glow。移除了会让星爆提前变白的整张星盘 Glow，保留局部辉光。

## 逐帧验证

最终预览为 1280×720、30 fps、2395 帧、79.833333 秒。逐帧解码检查通过，源与 v07 均从 0 帧对齐。白色星爆源片与 v07 都从第 2175 帧开始；v07 第 2173 帧白色覆盖约 0.026%，第 2175 帧约 0.984%。首尾保持一个 2395 帧循环；源第 2395、2396 帧仅用于下一轮接缝诊断。

这是可编辑的原生近似，不声称逐像素一致。细小星座拓扑、局部字形笔触、图标雕刻密度和颜色混合仍可能与原片存在差异。`Preview_Details_v07.html` 提供源片/v06 切换、整数帧定位、前后单帧、Shift 十帧和关键帧跳转。
